# SQLAdmin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить защищённую паролем админку SQLAdmin на `/admin` с CRUD, поиском и фильтрами для `User`, `TelegramProfile` и `AuthSession`.

**Architecture:** SQLAdmin монтируется в существующее FastAPI-приложение и использует тот же async engine. `Database` создаётся в `create_app`, а lifespan только освобождает его; админка включается при наличии `ADMIN_PASSWORD` и `AUTH_JWT_SECRET`, вход — по логину/паролю из `.env`, сессия — подписанная HttpOnly-cookie.

**Tech Stack:** Python 3.14, FastAPI 0.156.x, SQLAlchemy 2.x, Pydantic 2.x, SQLAdmin 0.32.x, `itsdangerous`, pytest, httpx.

**Spec:** `docs/superpowers/specs/2026-11-03-sqladmin-design.md`

## Global Constraints

- Устанавливается только `sqladmin[auth]`; extra `auth` обязателен для `SessionMiddleware`.
- `ADMIN_PASSWORD.strip()` пустой или отсутствующий `AUTH_JWT_SECRET` => админка не монтируется.
- В production при включённой админке `ADMIN_PASSWORD.strip()` длиной < 16 или содержащий `change-me` без учёта регистра => `ValidationError`.
- `ADMIN_SESSION_MAX_AGE_SECONDS` по умолчанию `43200`, значение должно быть > 0.
- Cookie: `milly_admin_session`, `Path=/admin`, `HttpOnly`, `SameSite=Lax`, `Max-Age=ADMIN_SESSION_MAX_AGE_SECONDS`, `Secure=AUTH_REFRESH_COOKIE_SECURE`.
- Пароль и HMAC-отпечаток не логируются и не попадают в ответы.
- Один `Database` на приложение; второй engine не создаётся.
- Публичный JSON API и его ошибки не меняются.
- `/admin` — HTML-интерфейс; ошибка логина (`400`) и необработанные ошибки SQLAdmin — документированное исключение из JSON-конверта.
- Все новые функции, методы и классы имеют докстринги по шаблону `AGENTS.md`.
- Тесты не требуют PostgreSQL, NATS или Redis.
- Реальные секреты не коммитятся; в `.env.example` только dev-плейсхолдеры.

## Review Focus

- Пустой или пробельный `ADMIN_PASSWORD` не должен включать админку; production не должен принимать `Change-Me` и короткие пароли.
- Формы `TelegramProfile` и `AuthSession` должны содержать `user_id`, иначе create/edit падает на non-nullable FK.
- Cookie админки должна иметь `Secure` в production и не иметь его в локальном HTTP-режиме.
- При выключенной админке `/admin` должен отдавать общий JSON `404`, а не оставлять смонтированный sub-app.
- Смена `ADMIN_PASSWORD` должна инвалидировать ранее выданную сессию.

def _request(
    *,
    form: dict[str, str] | None = None,
    session: dict[str, str] | None = None,
) -> Request:
    """Build a request with an optional URL-encoded form and session."""
    body = urlencode(form or {}).encode("utf-8")
    messages: list[Message] = [
        {"type": "http.request", "body": body, "more_body": False}
    ]

    async def receive() -> Message:
        """Return the next scripted request message."""
        if messages:
            return messages.pop(0)
        return {"type": "http.disconnect"}

    scope: Scope = {
        "type": "http",
        "method": "POST" if form is not None else "GET",
        "path": "/admin/login",
        "headers": [(b"content-type", b"application/x-www-form-urlencoded")],

```python
from __future__ import annotations

import hashlib
import hmac
import secrets

from pydantic import SecretStr
from sqladmin.authentication import AuthenticationBackend
from starlette.requests import Request


class AdminAuth(AuthenticationBackend):
    """Password-based session authentication for the SQLAdmin panel."""

    def __init__(
        self,
        *,
        username: str,
        password: SecretStr,
        secret_key: SecretStr,
        session_max_age_seconds: int,
        https_only: bool,
    ) -> None:
        """
        Initialize the admin authentication backend.

        Purpose:
            Configure the admin session cookie and the credential
            fingerprint used to invalidate sessions after a password change.

        Args:
            username: Admin login name.
            password: Admin password from configuration.
            secret_key: Secret used to sign the session cookie and fingerprint.
            session_max_age_seconds: Session cookie lifetime in seconds.
            https_only: Whether the cookie must carry the Secure flag.

        Notes:
            - The raw password is kept in memory for constant-time comparison.
            - The fingerprint is an HMAC-SHA256 of ``username:password``.
        """
        super().__init__(
            secret_key=secret_key.get_secret_value(),
            session_cookie="milly_admin_session",
            max_age=session_max_age_seconds,
            path="/admin",
            same_site="lax",
            https_only=https_only,
        )
        self._username = username
        self._password = password.get_secret_value()
        self._fingerprint = hmac.new(
            secret_key.get_secret_value().encode("utf-8"),
            f"{username}:{self._password}".encode("utf-8"),
            hashlib.sha256,
        ).hexdigest()

    async def login(self, request: Request) -> bool:
        """
        Validate submitted admin credentials and start a session.

        Purpose:
            Compare the login form against configured credentials without
            leaking which value was wrong.

        Args:
            request: Login request carrying a URL-encoded form.

        Returns:
            bool: True when the credentials match and the session is marked
                authenticated; False otherwise.

        Notes:
            - Both comparisons run to avoid short-circuiting on the username.
            - The session stores only the credential fingerprint.
        """
        form = await request.form()
        username = str(form.get("username", ""))
        password = str(form.get("password", ""))
        username_ok = secrets.compare_digest(
            username.encode("utf-8"),
            self._username.encode("utf-8"),
        )
        password_ok = secrets.compare_digest(
            password.encode("utf-8"),
            self._password.encode("utf-8"),
        )
        if not (username_ok and password_ok):
            return False
        request.session.update({"authenticated": self._fingerprint})
        return True

    async def logout(self, request: Request) -> bool:
        """
        Clear the admin session.

        Purpose:
            Remove the authenticated marker from the signed session cookie.

        Args:
            request: Request whose session is cleared.

        Returns:
            bool: Always True so SQLAdmin redirects to the login page.
        """
        request.session.clear()
        return True

    async def authenticate(self, request: Request) -> bool:
        """
        Validate the admin session fingerprint.

        Purpose:
            Reject missing, forged, or stale sessions, including sessions
            issued before the configured password was changed.

        Args:
            request: Request whose session is inspected.

        Returns:
            bool: True only when the stored fingerprint matches the current
                credentials.
        """
        fingerprint = request.session.get("authenticated")
        if not isinstance(fingerprint, str):
            return False
        return secrets.compare_digest(
            fingerprint.encode("utf-8"),
            self._fingerprint.encode("utf-8"),
        )
```

            foreign_model=User,
            title="User",
        ),
        OperationColumnFilter(TelegramProfile.telegram_id),
    ]

class AuthSessionAdmin(ModelView, model=AuthSession):
    """Admin view for refresh-token sessions."""

    column_list = [
        AuthSession.id,
        AuthSession.user_id,
        AuthSession.family_id,
        AuthSession.created_at,
        AuthSession.expires_at,
        AuthSession.revoked_at,
    ]
    column_details_exclude_list = [AuthSession.refresh_token_hash]
    column_searchable_list = [AuthSession.user_id, AuthSession.family_id]
    column_sortable_list = [
        AuthSession.id,
        AuthSession.created_at,
        AuthSession.expires_at,
        AuthSession.revoked_at,
    ]
    column_filters = [
        ForeignKeyFilter(
            AuthSession.user_id,
            User.id,
            foreign_model=User,
            title="User",
        ),
        OperationColumnFilter(AuthSession.family_id),
        OperationColumnFilter(AuthSession.created_at),
        OperationColumnFilter(AuthSession.expires_at),
        OperationColumnFilter(AuthSession.revoked_at),
    ]
    column_default_sort = (AuthSession.id, True)
    form_include_pk = True
    form_excluded_columns = [AuthSession.id]

SQLAdmin excludes both primary-key and foreign-key columns from forms

```python
from __future__ import annotations

import structlog
from fastapi import FastAPI
from sqladmin import Admin

from backend.admin.auth import AdminAuth
from backend.admin.views import AuthSessionAdmin, TelegramProfileAdmin, UserAdmin
from backend.core.config import Settings
from backend.db.session import Database

logger = structlog.get_logger(__name__)


def setup_admin(
    app: FastAPI,
    database: Database,
    settings: Settings,
) -> Admin | None:
    """
    Mount the SQLAdmin panel when admin credentials are configured.

    Purpose:
        Build the admin sub-application with password authentication and the
        three project model views, or leave it unmounted when disabled.

    Args:
        app: FastAPI application that receives the mounted admin.
        database: Shared database providing the async engine.
        settings: Application settings with admin credentials and flags.

    Returns:
        Admin | None: The configured admin instance, or None when the admin
            panel is disabled.

    Notes:
        - A missing or whitespace-only ``ADMIN_PASSWORD`` disables the panel.
        - ``AUTH_JWT_SECRET`` is required because it signs the session cookie.
        - No secret values are logged.
    """
    admin_password = settings.admin_password
    auth_jwt_secret = settings.auth_jwt_secret
    if not settings.admin_enabled or admin_password is None or auth_jwt_secret is None:
        logger.info(
            "admin.disabled",
            reason="ADMIN_PASSWORD or AUTH_JWT_SECRET is not set",
        )
        return None

    admin = Admin(
        app=app,
        engine=database.engine,
        base_url="/admin",
        title=f"{settings.app_name} Admin",
        authentication_backend=AdminAuth(
            username=settings.admin_username,
            password=admin_password,
            secret_key=auth_jwt_secret,
            session_max_age_seconds=settings.admin_session_max_age_seconds,
            https_only=settings.auth_refresh_cookie_secure,
        ),
        debug=settings.debug,
    )
    admin.add_view(UserAdmin)
    admin.add_view(TelegramProfileAdmin)
    admin.add_view(AuthSessionAdmin)
    logger.info("admin.mounted", base_url="/admin")
    return admin
```
